# Security

The public repository is about the offline-dictionary feature and owner-device
modding.

Please do not use public issues to post:

- credentials or personal identifiers;
- full proprietary firmware images;
- proprietary vendor binaries;
- unrelated vulnerability exploitation details;
- instructions targeting devices or networks you do not own/control.

If you discover a security issue in the vendor's update mechanism or another
vendor component, consider reporting it privately to the vendor through an
appropriate responsible-disclosure channel. Keep that disclosure separate
from this dictionary-mod project.

Security bugs in the original scripts in this repository can be reported
without attaching proprietary vendor files.
