# Disclaimer

This project documents modification of user-owned hardware.

- Use it only on a device you own or are authorized to modify.
- Make backups before changing system files.
- Binary patches are tested only against the hashes documented in this repo.
- Do not force a patch onto a different firmware build.
- Device modification can cause data loss or make the device temporarily or
  permanently unusable.
- Laws concerning reverse engineering, interoperability, warranty, and
  anti-circumvention vary by jurisdiction. Nothing in this repository is legal
  advice.

This repository intentionally avoids redistributing proprietary vendor
firmware/binaries and keeps unrelated security-disclosure material out of the
public modding instructions.
